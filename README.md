Скачать NVIDIA Sync можно с официального сайта NVIDIA для разработчиков. Ссылка для загрузки и подробные инструкции зависят от операционной системы вашего основного ПК.

### 💻 Прямая ссылка для скачивания

Основная страница для загрузки приложения находится здесь:

➡️ **Страница загрузки NVIDIA Sync: `https://build.nvidia.com/spark/connect-to-your-spark/sync`**

На этой странице вы найдете установочные файлы для Windows и macOS.

### 📋 Инструкции по установке для разных ОС

Вот как выглядит процесс установки для каждой из поддерживаемых систем, согласно официальной документации:

*   **Для Windows 11**: Скачайте установщик (`.exe` файл) по ссылке выше, запустите его и следуйте инструкциям на экране.
*   **Для macOS**: Скачайте файл `nvidia-sync.dmg`, откройте его и перетащите иконку приложения в папку «Программы» (Applications).
*   **Для Ubuntu 24.04 или новее**: Установка производится через терминал с использованием официального репозитория NVIDIA. Вам нужно будет выполнить несколько команд:
    1.  Сначала добавьте репозиторий и ключ безопасности:
        ```bash
        curl -fsSL https://workbench.download.nvidia.com/stable/linux/gpgkey | sudo tee -a /etc/apt/trusted.gpg.d/ai-workbench-desktop-key.asc
        echo "deb https://workbench.download.nvidia.com/stable/linux/debian default proprietary" | sudo tee -a /etc/apt/sources.list
        ```
    2.  Затем обновите списки пакетов и установите приложение:
        ```bash
        sudo apt update
        sudo apt install nvidia-sync
        ```

После установки приложение запустится автоматически (или его можно будет найти в меню «Пуск» / «Программы»), и вы сможете пройти первичную настройку для подключения к вашему DGX Spark.
